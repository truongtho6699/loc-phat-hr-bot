# Lộc Phát HR — Zalo Bot

Trang hướng dẫn và công cụ sao chép lệnh: https://truongtho6699.github.io/loc-phat-hr-bot/

- Hướng dẫn liên kết tài khoản nhân viên với bot.
- Sao chép lệnh Đồng ý, Không đồng ý, Xem chi tiết kèm mã đơn.
- Mở Mini App Lộc Phát HR.

Trang chỉ tạo văn bản để người dùng gửi cho bot; sao chép không thay đổi trạng thái đơn. GitHub Pages phục vụ trang tĩnh. Webhook bot và Apps Script cần được cấu hình riêng trước khi gửi/nhận tin thật.

Không đặt Bot Token, mật khẩu hoặc dữ liệu nhân sự trong repository này.
